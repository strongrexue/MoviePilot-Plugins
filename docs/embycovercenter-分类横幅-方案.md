# 「分类横幅」封面模板 —— 参考图拆解与可行性方案（v2 · 分区可调版）

> 目标：把参考图那种「左画面 / 右文字 / 金属字 + 光带」的分类横幅，做成封面中心里
> 一套**按元素独立定位**的布局（`分类横幅`），既能开箱即用，也能当小型排版器微调。

## 一、参考图在拆什么

六张图共用一套视觉系统，换的只有三样：**左区素材、主色相、文案**。

### 1. 版式（默认居中版式）

```
┌─────────────────────────────────────────────────────────────┐
│                                 │                           │
│                                 │        国 产 剧            │  ← 主标题（金属渐变）
│        左区：主视觉              │      ───────────          │  ← 光带（高光点在正中）
│      （人物 / 场景 / 海报）       │   C H I N E S E  S E R I E S │  ← 英文名（宽字距）
│                                 │      好故事  好人生         │  ← 中文标语
│                                 │   GOOD STORIES, ...        │  ← 英文标语
│                                 │                     （水印） │  ← 书法水印（竖排出血）
│ 爱情 ｜ 都市 ｜ 悬疑 ｜ 剧情      │                           │  ← 题材标签（固定左下）
└─────────────────────────────────────────────────────────────┘
```

| 元素 | 默认位置（归一化） | 关键参数 |
|---|---|---|
| 主标题 | 中心 x=76.2%，顶 y=33%，字高 17.5% | 字号 / 字距 / 对齐 / 最大宽度 |
| 光带 | 标题下 5%，宽 30%，高光点在 50% | 颜色 / 粗细 / 亮斑位置与强度 |
| 英文名 | 光带下 2.8%，字号 = 标题 ×0.225 | 字距 0.46em（可到 0.8） |
| 中文标语 | 英文名下 3%，段间距 0.85em | **间距可调**（0~3em） |
| 英文标语 | 中文标语下 2.6% | 字号 / 字距 / 对齐 |
| 题材标签 | 左下 4.2% / 91.8% | 位置 / 字号 / 字距 / 分隔符 |
| 书法水印 | 右侧 x=98.5%，竖排出血 | 整段标题 / 字号自动 / 可关闭 |
| 圆角边框 | 内嵌 0.35%，半径 4% | 半径 / 线宽 / 颜色 / 柔光 |

> **左对齐版式**只是把上面这些值换一组（标题 57.5% / 左对齐 / 光带宽 35.5%），
> 作为预设保留，随时切换。

### 2. 左区三种素材来源

| 来源 | 说明 | 谁提供 |
|---|---|---|
| 媒体库背景图 | `bg_url` + `backdrops` | 插件自动 |
| 媒体库海报阵列 | `posters` 叠成 3~5 张卡片 | 插件自动 |
| 成品主视觉（Mode B） | 一张 16:9 图，人物/场景都行 | 用户上传 / URL / 按库配置 / 以后 AI |

**Mode B 是这套模板的正解**：参考图那种「人物 + 轮廓光」是美术资产，
不该由插件运行时生成；插件负责版式、金属字、光带、调色、边框、水印。

## 二、可行性结论

| 判定项 | 结论 |
|---|---|
| 作为第 13 套布局加入 | ✅ 无需改前端（schema 自动生成表单） |
| 每个元素独立定位 | ✅ 一套坐标 + 链式对齐，已在本方案 mockup 跑通 |
| 全自动（不传底图） | ⚠️ 观感同设计语言，但左区是场景/海报，不是人物 |
| 传成品主视觉 | ✅ 基本等同参考图 |
| 题材标签按库预设 + 手填 | ✅ 一张映射表 + 手填优先 |
| 字体全部可改 | ✅ 每个文字元素一个 `type: font`；字体上传/列表 API 已有 |
| 水印整段标题 + 自动字号 + 可关 | ✅ 已实现于 mockup |
| 光带 / 亮斑颜色可调 | ✅ 两个颜色参数 |
| 动态封面 | ➖ 本版不做（不实现 `render_anim`，引擎自动走静态） |
| **人物抠像合成** | ❌ 无 alpha 素材，运行时做不出来（Mode B 兜底） |

### 需要接受的 4 个代价

1. **字段约 75 项**（8 个分组）。配置页会变长，需要分组折叠 + 每元素「恢复默认」。
2. **自由定位可能重叠/出界**。只做软约束：坐标夹在画布内、文字按最大宽度自动缩字号。
3. **水印和文字抢可读性**。默认 12% 透明度、右侧出血；想更清楚就降低透明度或关掉。
4. **Mode B 需要存图**。上传要走插件数据目录（类似字体），按库配置要一张映射表。

## 三、参数 schema（一步到位 · 约 75 项）

> 所有 `x/y/width/height/size` 都是**画布比例**（0~1），这样 1920 与 1280 输出一致；
> `tracking/spacing` 是 **em**（相对字号），换字体不会错位。

### 组 1 · 画布与输出（6）

| key | 类型 | 默认 | 说明 |
|---|---|---|---|
| `canvas_width` | number | 1920 | 画布宽 |
| `canvas_height` | number | 1080 | 画布高 |
| `output_width` | number | 0 | 0 = 原始 |
| `output_height` | number | 0 | 0 = 原始 |
| `frame_radius` | range 0-80 | 44 | 圆角 |
| `frame_border_width` | range 0-8 | 2 | 边框粗细 |

### 组 2 · 背景与底图（10）

| key | 类型 | 默认 | 说明 |
|---|---|---|---|
| `bg_source` | select | `library` | `library` 媒体库 / `posters` 海报阵列 / `keyart` 成品主视觉 |
| `keyart_upload` | text(base64) | `""` | 上传一张主视觉（存数据目录，按库复用） |
| `keyart_url` | text | `""` | 直接填图床/本地 URL |
| `keyart_per_library` | text(JSON) | `{}` | 按库指定底图：`{"库ID": "文件名或URL"}` |
| `keyart_focus_x` | range 0-100 | 50 | 裁剪焦点 X（防止裁到脸） |
| `keyart_focus_y` | range 0-100 | 50 | 裁剪焦点 Y |

### 组 8 · 书法水印（9）

| key | 类型 | 默认 | 说明 |
|---|---|---|---|
| `watermark_enabled` | boolean | true | **一键关闭** |
| `watermark_text` | text | `""` | 空 = **整段标题**（不是前两字） |
| `font_watermark` | font | `叶根友毛笔行书.ttf` | 缺失时自动跳过水印 |
| `watermark_size` | range 0-800 | 520 | 单字字号的**上限** |
| `watermark_max_height` | range 20-100 | 84 | 竖排总高上限 %，按字数自动缩 |
| `watermark_x` | range 0-120 | 98.5 | 大于 100 = 右侧出血 |
| `watermark_y` | range 0-100 | 50.0 | |
| `watermark_opacity` | range 0-30 | 12 | % |
| `watermark_rotate` | range -30-30 | -6 | 度 |

> **水印字号规则**：`单字 = min(watermark_size, 画布高 × max_height ÷ 字数 × 0.92)`。
> 所以「国产剧」3 字是 285px/字，「国产连续剧」5 字自动降到 171px/字，
> 竖排总高始终占画布 84%，不会溢出，也不会因为字多而挤爆。

## 五、实现方案

### 5.1 文件清单

| 文件 | 作用 |
|---|---|
| `service/layouts/分类横幅.py` | 布局本体：`get_schema()` + `render()`，约 700 行 |
| `defaults/templates/分类横幅-*.json` | 6 套预设参数 |
| `defaults/templates/分类横幅-*.jpg` | 640×360 缩略图 |
| `tests/v3/embycovercenter/test_layout_category_banner.py` | 回归测试 |
| `docs/mockups/category_banner_mockup.py` | 效果图生成器（参考实现，已跑通） |

### 5.2 关键实现点（mockup 已验证）

- **元素链**：标题决定锚点与对齐；英文名/标语 `inherit` 时共用同一锚点与对齐方式，
  改标题的对齐，整块一起变——但每个元素仍可单独覆盖。
- **金属字**：文字遮罩 + 纵向三段渐变 + 斜向高光带 + 柔光。
- **断崖压暗**：`smoothstep` 在 17% 宽度内吃满，而不是铺满全幅的线性渐变。
- **光带**：横向 alpha 衰减 + 50% 位置的高光椭圆（颜色/位置/强度独立）+ 2px 白芯。
- **水印**：整段标题竖排、字号按字数自动收缩、右侧出血（x>100%）、可整块关闭。
- **标签**：按库预设 → 手填覆盖 → 自动读取（三级优先级）。
- **自动缩字号**：标题/英文名/标语/标签都按最大宽度收缩，2~8 字都排得下。

### 5.3 性能

素材已缓存时，1920×1080 单张 **0.3~0.6s**（压暗/调色 ~0.2s、文字与模糊 ~0.15s、编码 ~0.1s）。
比海报墙（40 张图）轻，预览不会撞网关超时。

### 5.4 后端改动（P1）

| 项 | 工作量 |
|---|---|
| keyart 上传端点（存数据目录 + 白名单） | ~0.5 天 |
| 按库底图/标签映射（配置项 + 读写） | ~0.2 天 |
| Emby 题材读取（`/Genres?ParentId=`，10 分钟缓存，失败回退手填） | ~0.3 天 |

## 六、交付节奏

| 阶段 | 内容 | 工时 |
|---|---|---|
| **P0** | 布局本体 + 75 项 schema + 6 套预设 + 缩略图 + 回归测试 | 2~2.5 天 |

### 验收标准

1. 2~8 字库名批量渲染，右侧文字不越界、不重叠、不糊；
2. 640×360 缩略图下标题、英文名、标签可读；
3. 同配置逐像素一致（固定噪点种子）；
4. 无素材 / 极端参数 / 字符串参数不崩；
5. 预设 JSON 与 schema 字段完全对齐；
6. 水印开关、字号随字数自适应、缺字体自动跳过。

## 七、已确认的决策

| 项 | 决策 |
|---|---|
| 默认版式 | **居中**（左对齐作为可选预设） |
| 水印 | 右侧竖排**出血**；用**整段标题**；字号随字数自动收缩；**可关闭** |
| Mode B 底图 | **三种都做**：本地上传 / 填 URL / 按库配置 |
| 字段规模 | **一步到位（约 75 项）** |
| 标语间距 | 已从 1.9em 收紧到 **0.85em**，且可调（0~3） |
| 光带颜色 | 线与亮斑**各一个颜色参数** |
| 动态封面 | 不做 |
| 标签位置 | **固定左下**（居中版式也不动） |
| 字体 | 全部可替换（内置预设 + 上传） |
